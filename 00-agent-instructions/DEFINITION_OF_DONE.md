# Definition of Done

## Per feature

[ ] Acceptance criteria pass; [ ] parent/child flows tested; [ ] free/premium gates tested; [ ] permission denial/revocation tested; [ ] offline and reconnection tested; [ ] security/privacy tests pass; [ ] accessibility tested; [ ] real Android device validated; [ ] docs and traceability updated.

## Release

[ ] Both separate AABs signed using secure CI; [ ] backend deployed staging; [ ] Play policy and legal review; [ ] data safety declarations; [ ] subscriptions tested via Play sandbox; [ ] support runbook; [ ] human approval.
