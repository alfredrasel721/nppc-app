# Unit Test Requirements

## Android

Rule evaluation boundary times, timezone/DST, emergency allowlist, offline cache, sync version ordering, session consent state machine, subscription state display.

## Backend

RBAC, child-family scope, entitlement gates, idempotency, pairing expiry, request conflict, SOS dispatch, retention jobs.

## Coverage

Target 85% critical business logic; every security branch must have negative tests; coverage alone is not sufficient.
