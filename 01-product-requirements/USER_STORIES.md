# User Stories

## Parent

As a parent I can pair a child, set free time/app rules, view reports and location, respond to SOS, and manage subscription; if Premium I can request filters or live sessions subject to child and OS approval.

## Child

As a child I can see my limits, request more time, contact family, inspect monitoring state, and decline or stop a live session without hidden fallback.

## Co-guardian

As an invited guardian I can act only within assigned permissions and see who changed a rule.

## Support

As a support agent I can troubleshoot synchronization without reading sensitive child media.

## Acceptance

Each story maps to catalog IDs and platform checks; see `ACCEPTANCE_CRITERIA.md`.
