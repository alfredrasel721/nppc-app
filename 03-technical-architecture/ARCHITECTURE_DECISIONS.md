# Architecture Decision Records

## ADR-001

Separate Parent and Child Android applications with distinct application IDs; shared libraries permitted.

## ADR-002

All non-six named Premium features are Free, regardless of source [ADV] label.

## ADR-003

Android-only consumer product; original family web dashboard migrated to Parent Android.

## ADR-004

Visible per-session child approval + OS consent required for screen/camera/audio; no stealth or persistence.

## ADR-005

OpenAPI-first modular monolith; backend authoritative for entitlements, child local enforcement reports ack.

## ADR-006

Sensitive feature feasibility and Play policy are release blockers, not assumptions.
