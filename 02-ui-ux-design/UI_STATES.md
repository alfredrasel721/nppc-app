# UI State Matrix

## Rule states

draft, pending, enforced, failed, unsupported, permission_missing, disabled.

## Live states

requested, pending_child, declined, waiting_os_consent, active, ended, expired, disconnected, revoked.

## Subscription states

free, premium_active, grace_if_verified, expired, refunded, billing_unavailable.

## Offline

Show last known data with timestamp and stale label; allow offline local child SOS attempt; never fake live status.
