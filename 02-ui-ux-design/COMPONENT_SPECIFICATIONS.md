# Component Specifications

## Rule card

Displays feature, child, effective schedule, pending/enforced/failed status, last ack time, edit action.

## Premium gate

Explains named feature, plan state, required OS permission, privacy disclosure; no paywall on security, consent or SOS.

## Child live consent

Full-screen/clear dialog with requesting guardian, mode, scope, duration, Allow and Decline. No preselected acceptance; Android system prompt remains required.

## Live indicator

Always-on foreground notification and in-app stop; shows guardian, elapsed time and session mode.

## Errors

Human-readable next action; distinguish OS unsupported from missing permission, lack of subscription, no network and child decline.
