# Navigation Structure

## Parent

Bottom tabs: Home, Rules, Location, Requests, Family. Account and Premium from Family. Sensitive live modes are nested and never auto-start.

## Child

Bottom tabs: Today, Requests, Safety, Family, Privacy. Persistent session stop control is always available while active.

## Deep links

Authenticated deep links for alerts and approvals only; never start media capture or privileged actions directly from a push notification.
