# Performance Requirements

## Latency

Parent dashboard p95 <3s target; rule sync p95 <30s online target; session stop p95 <2s after child action target.

## Battery

Measure child app background battery and data impact on 24-hour physical device test; set release threshold from pilot baseline.

## Load

Benchmark 1k, 10k and 100k simulated family counts before scaling claims; protect SOS under load.
