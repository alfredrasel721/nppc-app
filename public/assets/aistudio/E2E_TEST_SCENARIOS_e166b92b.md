# End-to-End Scenarios

## Family

Create family, pair Android child, grant minimal permissions, configure free limit, request extra time, parent approves, child sees new allowance.

## Premium

Purchase sandbox subscription, configure web filter, request screen session, child declines; retry with child acceptance and OS prompt; stop; refund; verify all Free features still work.

## Emergency

During downtime, child reaches SOS, parent gets alert and location timestamp; offline retry; no duplicated event.

## Accessibility

TalkBack through child live consent and stop; font scaling and tablet layout.
