# Release Checklist

## Technical

[ ] Two separately signed Android bundles; [ ] backend migrations and rollback; [ ] CI green; [ ] crash reporting; [ ] real device test report; [ ] server purchase verification; [ ] FCM; [ ] kill switches.

## Safety

[ ] No covert capture; [ ] child consent and stop; [ ] permission revocation; [ ] emergency reachable; [ ] security pen test; [ ] child data retention; [ ] support role audit.

## Legal/store

[ ] Human review of Play policy, Families, age verification, location, SMS/call log, accessibility, foreground service, media projection, Data safety form, subscription terms, privacy notice.

## Approval

[ ] Named human product owner, legal/security and release manager approve production release.
