# Roles and Permissions

## Primary guardian

Can create family, enroll child, set rules, grant scoped co-guardian access, manage purchases, request Premium sessions. Cannot override child OS capture consent.

## Co-guardian

Can read/edit only assigned child resources and explicitly delegated capabilities; subscription management reserved for owner; no automatic sensitive-session access.

## Child

Can view policy, request exceptions, SOS, check in, view audit and accept/decline/end live sessions; cannot edit guardian policy without authorized flow.

## Emergency contact

Receives explicitly configured SOS and time-limited location only; no routine tracking or premium surveillance.

## Staff/system

Support can access diagnostics with audited, time-limited permission; system workers act under scoped service identity. No routine access to child content.
