# Monitoring and Logging

## Metrics

Rule ack latency, FCM delivery, SOS dispatch, pairing errors, permission failure rates, purchase verification, session stop latency, API latency/crashes.

## Privacy

No child precise location, message content, notification bodies or live media in telemetry. Hash/pseudonymize IDs, restrict log access.

## Alerts

Unauthorized session attempt, unexpected live session after child stop, cross-family authorization errors, SOS delivery failure and elevated crash rates.
