# Child Safety Policy

## Principles

Transparent supervision, no covert monitoring, child-facing explanation, emergency reachability, proportionate data collection, guardian verification.

## Live sessions

Only visible and actively child-approved; session can be ended; deny and timeout are valid outcomes. Never use force/stealth to override child choice.

## Sensitive content

No content harvesting or bypassing encrypted messaging; content classification only via lawful, supported, disclosed methods.

## Escalation

Abuse report path; suspend suspicious guardian access pending human review; do not expose child data to support by default.
