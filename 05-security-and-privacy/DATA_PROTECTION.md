# Data Protection

## Classification

Public UI assets; internal operational data; confidential family records; restricted precise location, session data and notification-related data.

## Handling

Encrypt in transit and at rest, minimize retention, segregate family access, pseudonymize analytics, avoid raw sensitive data in crash logs.

## Deletion

Verify guardian authorization, queue erasure across database/backups under documented retention windows, issue confirmation and preserve minimal compliance audit only if required.
