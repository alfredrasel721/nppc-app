# Implementation Plan

## 0 — requirements

Human approves jurisdiction, target ages, device policy, pricing, branding and Android SDK support. Conduct Android/Play policy capability spike.

## 1 — platform foundation

Create independent Android Gradle apps, backend service, database migrations, auth, FCM, observability, test harness.

## 2 — Free critical path

Family/pairing, child permissions, time/app limits, schedules, reports, requests, SOS, location, guardian roles, privacy rights.

## 3 — Free full catalog

Implement remaining Free features in catalog, mark unsupported integrations with evidence; do not silently drop source ADV items.

## 4 — Premium

Play Billing verification and entitlement tests; web/social/notification filter feasibility; separately reviewed visible child-approved live sessions.

## 5 — hardening

E2E on physical devices, threat model, abuse review, accessibility, compliance and human release approval.
