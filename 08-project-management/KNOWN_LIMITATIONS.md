# Known Limitations

## Android

OS/OEM variability; app locks and install approvals cannot be guaranteed; background location and notification access require special handling; Accessibility and device admin have policy constraints.

## Sensitive

MediaProjection requires OS consent; camera/mic require foreground-visible access; notification filtering is limited; social-media content inside encrypted apps is generally not available.

## Source

Original checklist contains optional web dashboard, iOS comparison, wearables and school features; user has overridden consumer web and iOS scope. Wearables/school remain optional Free candidate features.

## Production

This zip is a documentation and scaffold package, not compiled apps, a security audit or Play Store approval.
